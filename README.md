# Maura Portfolio Starter

Vanilla HTML/CSS/JS. No React, build tooling, or CMS required.

## Run
Open this folder in VS Code and use Live Server, or run:
`python3 -m http.server 8000`
Then visit `http://localhost:8000`.

## Content
- Edit `js/data.js` for projects, text, image/video paths, and row order.
- Put local files under `assets/` and replace placeholder paths.
- Use `index.html` for the homepage and `project.html?slug=venmo` for project detail.
- `css/styles.css` contains all responsive styles.
- `js/site.js` renders projects, horizontal rows, and hover letters.

## Notes
Placeholder art is intentionally used until real files are supplied. Social URLs can be added as links; for embedded posts use their official embed code where permitted. YouTube media uses privacy-enhanced embeds.
